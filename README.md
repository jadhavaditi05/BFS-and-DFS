## Overview

This project compares the performance of two uninformed search algorithms:

- Breadth-First Search (BFS)
- Depth-First Search (DFS)

Both algorithms are tested on the same graph using the same start and goal nodes.

The experiment measures:

- Number of nodes expanded
- Execution time
- Runtime profiling using `py-spy`

---

## Graph Used

A graph containing **17 nodes** is used.

**Start Node:** A  
**Goal Node:** Q

```text
                         A
                       /   \
                      B     C
                    /  \   /  \
                   D    E F    G
                  / \  / \ / \ / \
                 H  I J  K L  M N  O
                                      |
                                      P
                                      |
                                      Q
The graph contains the following connections:

A → B, C
B → D, E
C → F, G
D → H, I
E → J, K
F → L, M
G → N, O
O → P
P → Q

Algorithms
Breadth-First Search (BFS)

BFS explores the graph level by level and uses a queue.

Time Complexity: O(V + E)
Space Complexity: O(V)

Depth-First Search (DFS)

DFS explores a branch deeply before backtracking and uses a stack.

Time Complexity: O(V + E)
Space Complexity: O(V)

Methodology

Both BFS and DFS were tested using:

The same 17-node graph
Start node A
Goal node Q
Same Python environment

The benchmark program performs 100,000 searches for each algorithm using Python's timeit module.

The average execution time is calculated in microseconds per search.

Experimental Results
Node Expansion Results
Algorithm	Start	Goal	Nodes Expanded
BFS         	A	  Q	        17
DFS	            A	  Q	        17

Both BFS and DFS expand all 17 nodes before reaching the goal node Q with the given graph structure and traversal order.

Execution Time

The benchmark is performed using timeit.

Run the following command to obtain the actual execution-time results:

The exact execution time depends on the computer, Python version, system load, and other system conditions.

Conclusion

This experiment demonstrates the practical performance analysis of BFS and DFS using execution-time measurements and runtime profiling.

For the selected 17-node graph, both BFS and DFS expand 17 nodes when searching from A to Q.

The execution-time results are obtained using Python's timeit module. Runtime profiling is performed using py-spy.

Actual execution time can vary depending on the graph, implementation, Python environment, computer hardware, and system conditions.
